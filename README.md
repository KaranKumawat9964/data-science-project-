# 📊 Student Performance Analysis and Prediction using Machine Learning

## 🚀 Project Overview

This project is an end-to-end Data Science and Machine Learning project that analyzes student academic performance and predicts final grades using Python.

The project explores the relationship between study time, absences, previous grades, and final grades. It includes data analysis, visualization, model training, and evaluation.

## 🎯 Project Objectives

* Analyze a real-world student performance dataset.
* Perform data exploration and statistical analysis.
* Create meaningful data visualizations.
* Build a Machine Learning model to predict final grades.
* Evaluate model performance using appropriate metrics.

## 🛠️ Technologies Used

* Python
* Pandas
* Matplotlib
* Seaborn
* Scikit-learn
* Google Colab
* Jupyter Notebook

## 📂 Dataset

**Dataset:** Student Performance Dataset
**Source:** UCI Machine Learning Repository

Dataset link: https://archive.ics.uci.edu/dataset/320/student+performance

The dataset contains student information, including study time, absences, and academic grades.

## ⚙️ Project Workflow

1. Import Python libraries.
2. Download and load the dataset.
3. Explore dataset structure and missing values.
4. Calculate descriptive statistics.
5. Visualize study time and final grades.
6. Analyze correlations between academic variables.
7. Split data into training and testing sets.
8. Train a Random Forest Regressor model.
9. Evaluate the model using MAE and R² score.
10. Compare actual grades with predicted grades.

## 📈 Data Visualization

The project includes:

* Study Time vs Final Grade scatter plot
* Student Performance Correlation Heatmap
* Actual vs Predicted Grades plot

These visualizations help explore patterns and relationships in the dataset.

## 🤖 Machine Learning Model

**Algorithm:** Random Forest Regressor

**Input Features:**

* Study Time
* Absences
* First Period Grade (G1)
* Second Period Grade (G2)

**Target Variable:** Final Grade (G3)

**Evaluation Metrics:**

* Mean Absolute Error (MAE)
* R² Score

The model is trained on a training dataset and evaluated on a separate test dataset.

## ▶️ How to Run the Project

1. Open the notebook in Google Colab.
2. Run all code cells in order.
3. Allow the dataset to download.
4. Review the data analysis and visualizations.
5. Check the Machine Learning model's evaluation results.
